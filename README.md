# 风暴拦截 · STORM INTERCEPT

雷暴越过警戒线，城市上空不断坠落「风暴核心」。你是「苍穹之矛」的最后一名操作员：瞄准、开火、积攒雷霆脉冲，在核心坠入城市前将它们全部击穿。

## 运行

直接双击 `index.html` 用浏览器打开即可。推荐使用较新的 Chrome / Edge。

也可以启动一个本地静态服务器：

```powershell
python -m http.server 8000
# 然后访问 http://localhost:8000
```

单文件版 `风暴拦截.html` 已内联全部样式与脚本，适合直接分享。

## 操作

| 操作 | 键鼠 / 触摸 |
| --- | --- |
| 瞄准 | 移动鼠标 / 按住屏幕拖动 |
| 开火 | 按住鼠标左键 / 按住屏幕 |
| 雷霆脉冲 | `E`、`空格` 或右键；触摸端使用右下角按钮 |
| 暂停 | `P` / `Esc` |
| 静音 | `M` |
| 开始 / 重开 | `Enter` |

雷霆脉冲需要充能至 100% 才能释放，会以链式闪电清扫全屏核心。

## 玩法

- 击穿核心可获得分数与脉冲能量，连续击穿会累积连击倍率。
- 城市完整度归零则防线失守。每次成功拦截一波会修复少量城市完整度。
- 每波结束可选择一项永久强化：射速、伤害、分叉电弧、脉冲效率、减伤、暴击或紧急抢修。
- 每 5 波会出现「风暴之眼」首领，它会召唤小型风暴核心并持续下降，必须在它抵达城市前摧毁。
- 历史最佳分数与静音设置会保存在浏览器本地。

## 特性

- 全程序化画面：风暴云层、霓虹城市、雨幕、闪电、粒子和屏幕震动均为实时绘制。
- 全部音效由 Web Audio 合成，无任何外部图片、音频或字体依赖。
- 自适应桌面与移动端布局，支持鼠标、键盘和触摸。
- 单文件离线版本可直接分享。
